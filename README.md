# GTooli 🚀

A collection of free, fast, and simple online web utilities, text tools, and calculators that run directly in your browser. 

👉 **Live Website:** [GTooli](https://mc170201270-rgb.github.io/gtooli/)

---

## ✨ Features

GTooli is designed for speed and simplicity. Most tools execute locally on the client-side, meaning your data never leaves your browser:

* **📝 Text Tools:** Word counter, case converter, remove duplicate lines, text cleaner, slug generator, reverse text, and line counter.
* **🔢 Calculators:** Percentage calculator, percentage change, discount calculator, age calculator, and BMI calculator.
* **🌐 Utilities:** Length converter, password generator, JSON formatter, and URL encoder/decoder.
* **🖼️ Image Tools:** Image compressor, image resizer, and image format converter (PNG, JPEG, WebP).
* **📱 Creator Tools:** Instagram caption helper, hashtag generator, social bio generator, YouTube title ideas, and social post ideas.

---

## 🛠️ Built With

* **HTML5** & **CSS3** (Modern layout and styling)
* **Vanilla JavaScript** (Client-side functionality with zero external bloat)
* **GitHub Pages** (Fast, reliable, free static hosting)
